# RadarAI

## Vision

RadarAI is an AI-powered Sales Intelligence platform designed to help sales teams discover companies, enrich data, detect buying signals, score opportunities, and automate prospecting.

---

## Tech Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS
- shadcn/ui
- Prisma 7
- Neon PostgreSQL
- TanStack Query
- TanStack Table
- Zod

---

## Current Modules

- Dashboard
- Companies
- Search (planned)

- AI Copilot (planned)
